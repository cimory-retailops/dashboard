Menyinkronkan Data Operasional

Mohon tunggu sebentar, sistem sedang memuat ringkasan kunjungan terbaru...

Panduan Pengguna & Manual Operasional

Sistem Cimory MDS Retail Ops (DK, LK, LP)

1. Arsitektur & Keamanan Data (Zero-Impact Production)

Dashboard ini mengkonsolidasikan 18 Google Spreadsheet terpisah (Modul DK: 6 Sheet, LK: 5 Sheet, LP: 4 Sheet, + 3 Sheet Absen) ke dalam satu pintu antarmuka tanpa merusak struktur atau formula Google Sheet asli.

✅ 100% Read-Only: Script Google Apps Script hanya membaca data (openById). Tim lapangan tetap dapat menginput data di AppSheet seperti biasa tanpa risiko bentrok.
2. Mode Tabel On-Demand (Performa Super Cepat & Ringan)

Saat pertama kali dibuka, web fokus memuat Resume & Analitik agar loading instan. Data rincian tabel baru akan dimuat otomatis saat Anda memilih Filter (Modul / Retailer / MDS / Tanggal / Pencarian) atau mengklik tombol "Muat Semua Data Tabel".

3. Filter Tanggal Presisi & Rentang Tanggal (Date Range VLOOKUP)

Gunakan Date Picker (Dari Tanggal s/d Sampai Tanggal) untuk menyaring riwayat kunjungan pada rentang hari tertentu secara presisi. Tersedia juga preset instan: Hari Ini, 7 Hari Terakhir, 30 Hari Terakhir, dan Bulan Ini.

4. Fitur Tema (Light & Dark)

Klik ikon ☀️ / 🌙 pada header kanan atas. Light Mode cocok untuk ruangan terang/proyektor, dan Dark Mode nyaman untuk pemantauan malam hari. Preferensi Anda otomatis tersimpan di browser.

5. Sistem Role (Admin vs Field MDS)

Klik tombol Role Switcher di header. Pilih Admin / Supervisor untuk analitik seluruh modul, atau Field MDS untuk memfilter kunjungan khusus petugas tertentu.

5. Bukti Foto & Galeri Rak

Klik tombol "Selfie" untuk melihat foto kedatangan di toko, atau tombol "Before / After" untuk membuka galeri foto rak pajangan.

6. Export CSV & Google Maps

Klik tombol "Export CSV" untuk mengunduh data terfilter ke Excel. Klik ikon mata (👁️) untuk melihat detail kunjungan dan rute di Google Maps.

7. Pertanyaan Umum & Sinkronisasi Data (FAQ)

Data baru belum muncul? Google Apps Script menerapkan auto-cache 5 menit demi performa tinggi. Klik tombol "Sync Resume" di header untuk memaksa penarikan data terbaru langsung dari Google Sheets.
